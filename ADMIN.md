# Админка каталога

Локальный адрес: `http://127.0.0.1:8000/admin`. После публикации используйте
`https://green-courtyard.space/admin`. Вход — только по паролю; логина нет.

## Товары

В разделе «Товары» есть поиск по названию, артикулу и URL, фильтр по группе.
В карточке меняются название, артикул, группа и подгруппа, категория,
описание, цена, количество, наличие, характеристики и фотография. Пустое
количество означает, что число не подтверждено. При указанном количестве
статус определяется автоматически: `0` — нет в наличии, больше `0` — в наличии.
URL карточки остаётся прежним при переименовании, чтобы не терять поисковую
индексацию и внешние ссылки. Изменения сразу видны в каталоге, карточке и
подборках. История версий не ведётся.

Фото можно выбрать из уже существующих файлов `/img/…` или загрузить через
форму. Допускаются JPEG, PNG и WebP до 5 МБ. Загруженные файлы и правки
хранятся в приватном каталоге `DATA_DIR` (`backend/` при локальном запуске,
`/data` в Docker), отдельно от исходников. Сохраняйте резервную копию этого
каталога вместе с заявками.

## Заявки и бот

Раздел «Заявки» показывает обращения с сайта и позволяет менять статус.
MAX-бот уведомляет о новых обращениях, меняет статусы кнопками, показывает
статистику и отправляет CSV. Подключение: раздел MAX → одноразовая ссылка →
свой личный диалог. Подробная инструкция — [MAX.md](MAX.md).
Telegram-боты больше не запускаются.

## Пароль и безопасность

`SITE_ADMIN_PASSWORD` используется только в `/admin`. На сервере он хранится
в закрытом `.env`; локально приложение читает `backend/local_site_password.txt`
с правами 0600. Пароль сайта в MAX передавать не требуется: доступ выдаётся
одноразовой ссылкой из авторизованной админки. Можно подключить несколько личных диалогов, создав отдельную ссылку для каждого человека.
При отсутствии пароля веб-админка закрыта.

Сессия хранится на сервере, а браузер получает cookie `HttpOnly`,
`SameSite=Strict` и `Secure` на HTTPS. Закрытые формы защищены CSRF-токеном
и проверкой `Origin`. Три ошибочных входа с одного IP блокируют вход на
один час. Бездействующая сессия истекает через 30 минут, общий предел —
8 часов. Выход из админки завершает текущую сессию. Пароль не передаётся
через URL и не записывается в журналы.

Для смены пароля сайта обновите переменную в `.env` (или локальный закрытый
файл) и перезапустите приложение. После перезапуска веб-сессии завершатся.
Для отмены доступа MAX используйте кнопку нужного диалога в /admin/max. Замена токена MAX
также отменяет привязку; повторное подключение — по новой ссылке.
